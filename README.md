# SHUSH

SHUSH is a dark premium gamer team site built with Vite, React, TypeScript, Tailwind CSS, Framer Motion and lucide-react.

## Local Development

```powershell
pnpm install
pnpm run dev
```

## Validation

```powershell
pnpm run typecheck
pnpm run build
pnpm run preview
```

## Site Structure

- Home
- Roster
- Drop 01
- About

The Drop 01 flow is manual. There is no checkout, payment integration or backend in this project.
