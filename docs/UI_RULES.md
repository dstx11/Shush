# SHUSH UI Rules

## Priority Order
1. Text alignment and hierarchy
2. Home hero
3. Jersey showcase
4. Header/nav
5. Mobile layout
6. Roster professionalism
7. Drop 01 launch page
8. About page
9. Motion and microinteractions
10. Performance/accessibility cleanup

## Alignment
- Align headings, body copy and CTAs intentionally.
- Avoid orphaned buttons and disconnected labels.
- Keep cards in consistent rows when possible.
- Keep nav items evenly spaced.
- Avoid random floating text.

## Mobile
- Design for 360px width.
- Prevent horizontal scroll.
- Collapse grids before text becomes cramped.
- Make tap targets comfortable.
- Reduce motion and hover-only effects.
- Keep nav readable and closeable.

## Forms
Drop 01 remains a manual request flow.

Rules:
- labels are required
- useful input names are required in final implementation
- generated output needs `aria-live`
- button feedback should be clear
- do not imply checkout/payment unless a real flow exists

## Cards
Use cards for repeated content and tools, not for wrapping every section.

Cards should:
- have clear hierarchy
- keep content aligned
- avoid nested card clutter
- preserve readable contrast

## Footer
Footer should include SHUSH and Backora credibly. Keep it compact and functional.
