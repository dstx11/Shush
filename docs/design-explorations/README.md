# SHUSH art-direction sketches

Three standalone HTML explorations using the same authentic roster content. Serve the repository root and map `/assets/` to `public/assets/` to view their images. These documents are outside the Vite public directory and are not shipped as public pages.

- `atelier.html`: fashion editorial, arched image and quiet navigation.
- `protocol.html`: contained tactile controls and compact tactical UI.
- `nocturne.html`: immersive portrait composition and expansive typography.

Desktop (1366px) and mobile (390px) screenshots for all three directions were generated and reviewed from GitHub Actions run 44065348020, artifact `design-review`. The selected direction combines Atelier typography/framing with restrained Nocturne atmosphere. The pure Nocturne concept obscures the portrait with its CTA on mobile; Protocol reads as a generic tactical dashboard. The static sketches are visual alternatives, not a keyboard-tested replacement for the functional roster. Consult the dated evidence entry in `../SHUSH-DESIGN-INTELLIGENCE.md` for validation and outstanding work.
